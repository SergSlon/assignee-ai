## How to use

1. Work through each unchecked item. When complete, change `[ ]` to `[x]` and add an evidence citation in the `Notes` column.
2. Run the gate locally: `bash apps/cli/scripts/test-release-checklist-gate.sh` — must exit 0 only when all items are checked.
3. When ALL 12 items are `[x]`, obtain explicit user authorisation, then:
   - Remove `"private": true` from `apps/cli/package.json`.
   - Add `"publishConfig": { "access": "public" }` (or equivalent registry config).
   - Set the `ASSIGNEE_RELEASE_PUBLISH=1` GitHub Actions variable (see `.github/workflows/release.yml` header).
   - Trigger the release workflow.

Manual dispatch at `.github/workflows/check-release.yml`.
Run it before any publish attempt to catch regressions in this file.
