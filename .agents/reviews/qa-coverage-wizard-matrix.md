## GAPS

**MEDIUM severity**

- **AC 3**: No integration test exercises the option-elicitor's history-pop loop with a real multi-field plugin. Tests verify the sentinel plumbing but not that selecting Back on field N re-prompts field N-1 with prior answers preserved. Suggest adding one end-to-end test that drives a 3+ field plugin (e.g., EC2_INSTANCE) with a forward→back→forward sequence.
- **AC 10 (pattern branch)**: showIf conditionals using regex `pattern` are only verified via the static `evaluateShowIf` mirror check (conditionals.test.ts:202-236). The drive-based branches (lines 271-277, 291) explicitly skip pattern conditionals. Plugins like EC2_INSTANCE with `^t[34]` burstable-gated fields have no driven coverage of the hidden-field path.

**LOW severity**

- **AC 4**: Depends on `showBack=false` being passed at step 1 — asserted at the renderer layer only, not at the option-elicitor caller layer. A regression where the elicitor forgets to pass `false` would not be caught.
- **AC 6**: `property_path` segment-match is a string-split heuristic — robust for simple paths, fragile for indexed/compound paths.
- **AC 9**: Rule count assertion is `≥30`, not `==32` — accepts silent rule drift.
- **AC 11**: Tests resolve fetchers directly; don't cover user-selection-from-list UX.
- **AC 12**: "End-to-end" means plugin hook inspection, not full wizard→plan integration.

**HIGH severity**

- None.
