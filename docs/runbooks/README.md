# Runbooks

Operational how-to guides for on-call operators.

> **Course-project framing.** Assignee.ai is a final project for the
> "Generative AI for Developers" micro-master's program. The runbooks
> below document incident-response patterns as they would apply if the
> CLI were operated in a production-like environment; for course
> evaluation they are illustrative rather than the artefacts of a live
> on-call rotation.

| Runbook                                      | Scope                                                                                                                                                            |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [incident-response.md](incident-response.md) | Incident classification, first-30-min triage, evidence collection, common-incident playbooks, rollback procedures, post-mortem template, communication templates |
